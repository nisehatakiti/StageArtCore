# StageArt テーマ設計

## 方針

コンテンツ配置（SiteStructure / ProductionLayout）とデザインテーマを分離する。テーマ変更ではコンテンツ構成を変更しない。

## 対象

- 団体ホームページ: ライト系3種、ダーク系3種、カスタム
- 公演ホームページ: 共通6種に加えてライト・ポスター、ダーク・ドラマ、モノクロ、カスタム

## テーマ要素

- 背景色
- 面／カード色
- 本文色
- メイン色
- アクセント色
- 境界線色
- 見出しフォント
- 本文フォント

## 管理UI

コンテンツ配置と同じ管理導線からテーマを選択できるようにする。テーマ選択とカスタム設定は保存値として独立して保持し、将来のプレビュー機能からも再利用できる構造にする。

## 実装方針

`Theme` がプリセット定義とカスタム既定値を一元管理する。公開テーマはCSSカスタムプロパティへ変換して適用する。公演テーマは公演単位で保持し、団体テーマとは独立して変更可能とする。
